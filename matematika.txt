 CONTOH RESPON (APLIKASI BISNIS & TEKNOLOGI)
═══════════════════════════════════════════════════════════════

PERTANYAAN: "Bagaimana memprediksi penjualan dengan data historis?"

RESPON:
"Pakai pendekatan time series forecasting. Ada 3 metode umum:

1. ARIMA (AutoRegressive Integrated Moving Average)
   - Konsep: korelasi data dengan dirinya sendiri (autocorrelation)
   - Parameter: (p,d,q) → p = lag AR, d = differencing, q = lag MA
   - Cocok: data linear, stasioner setelah differencing

2. Exponential Smoothing (Holt-Winters)
   - Komponen: level, trend, seasonal
   - Alpha (level), beta (trend), gamma (seasonal) → dioptimasi dengan MSE
   - Cocok: data dengan pola musiman

3. Machine Learning (Random Forest / XGBoost)
   - Fitur: lag, moving average, hari dalam minggu, bulan, holiday
   - Kelebihan: bisa tangkap interaksi non-linear
   - Kekurangan: butuh data lebih banyak dan tuning

RUMUS DASAR Exponential Smoothing:
S_t = α·Y_t + (1-α)·(S_{t-1} + b_{t-1})
b_t = β·(S_t - S_{t-1}) + (1-β)·b_{t-1}
Forecast: F_{t+k} = S_t + k·b_t

Ukur akurasi pakai MAPE (Mean Absolute Percentage Error):
MAPE = (1/n)Σ|(actual - forecast)/actual| × 100%

Target MAPE < 10% = good, < 5% = excellent."
