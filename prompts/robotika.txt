═══════════════════════════════════════════════════════════════
 KONSEP & TEORI FUNDAMENTAL
═══════════════════════════════════════════════════════════════

【KINEMATIKA — DENAVIT-HARTENBERG (DH)】
• 4 parameter: θ (joint angle), d (offset), a (link length), α (twist)
• Transformasi: T = Rot_z(θ) × Trans_z(d) × Trans_x(a) × Rot_x(α)
• Forward kinematics: posisi end-effector dari joint angles
• Inverse kinematics: joint angles untuk mencapai posisi target

RUMUS SEDERHANA (2-link arm):
x = L₁cosθ₁ + L₂cos(θ₁+θ₂)
y = L₁sinθ₁ + L₂sin(θ₁+θ₂)

【KONTROL PID — 3 KOMPONEN】
• P (Proportional): respon terhadap error saat ini → Kp × e(t)
• I (Integral): akumulasi error → Ki × ∫e(t)dt
• D (Derivative): laju perubahan error → Kd × de(t)/dt

Output: u(t) = Kp·e(t) + Ki·∫e(t)dt + Kd·de(t)/dt

Tuning PID: Ziegler-Nichols, auto-tuning, trial-error

【SLAM (Simultaneous Localization and Mapping)】
• Tujuan: bangun peta lingkungan sambil menentukan posisi robot
• Algoritma: Extended Kalman Filter (EKF), FastSLAM, Graph-based (iSAM, GTSAM)
• Sensor: LIDAR, camera (monocular/stereo), depth, IMU, encoder

【PATH PLANNING — ALGORITMA TERPOPULER】
• Dijkstra: shortest path di graph berbobot → optimal tapi lambat
• A* (A-star): Dijkstra + heuristic → lebih cepat (gunakan Euclidean distance)
• RRT (Rapidly-exploring Random Tree): untuk ruang high-dimensional
• PRM (Probabilistic Roadmap): untuk static environment, bisa offline

【REINFORCEMENT LEARNING — CORE COMPONENTS】
• State: kondisi robot (posisi, kecepatan, sensor)
• Action: aksi yang bisa dilakukan (gerak, grab, rotasi)
• Reward: feedback dari lingkungan (positif: sukses, negatif: gagal)
• Policy: strategi mapping state → action
• Q-learning: Q(s,a) = R(s,a) + γ·max Q(s',a')
