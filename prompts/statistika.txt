═══════════════════════════════════════════════════════════════
 RUMUS & KONSEP FUNDAMENTAL
═══════════════════════════════════════════════════════════════

【STATISTIKA DESKRIPTIF】
• Mean: μ = (1/n)Σx_i
• Varians: σ² = (1/n)Σ(x_i - μ)²
• Standar deviasi: σ = √σ²
• Kuartil: Q1 (25%), Q2/median (50%), Q3 (75%)
• IQR = Q3 - Q1 → untuk deteksi outlier: < Q1 - 1.5×IQR atau > Q3 + 1.5×IQR

【STATISTIKA INFERENSIAL — UJI HIPOTESIS】
• H₀: tidak ada efek, H₁: ada efek
• Statistik uji → p-value
• α (significance level) biasanya 0.05 atau 0.01
• Tolak H₀ jika p-value < α

RUMUS Z-score (untuk proporsi):
z = (p̂ - p₀) / √(p₀(1-p₀)/n)

RUMUS t-test (satu sampel):
t = (x̄ - μ₀) / (s/√n)
df = n-1

【REGRESI LINEAR】
• Model: y = β₀ + β₁x₁ + β₂x₂ + ... + βₖxₖ + ε
• Koefisien: β̂ = (XᵀX)⁻¹Xᵀy
• R²: proporsi varians yang dijelaskan model
• MSE = (1/n)Σ(yᵢ - ŷᵢ)²

【DISTRIBUSI PROBABILITAS PENTING】
• Normal (Gaussian): N(μ, σ²) → continuous, symmetric, empirical rule 68-95-99.7
• Binomial: Bin(n,p) → discrete, jumlah sukses dalam n percobaan
• Poisson: Pois(λ) → discrete, count of rare events over time/space
• T-distribution: mirip Normal dengan ekor lebih tebal (sample size kecil)
• Chi-square: goodness of fit, test of independence

【MACHINE LEARNING METRICS】
• Accuracy = (TP+TN)/(TP+TN+FP+FN)
• Precision = TP/(TP+FP) → seberapa akurat positive prediction
• Recall = TP/(TP+FN) → seberapa banyak positive terdeteksi
• F1 = 2 × (P×R)/(P+R) → harmonic mean precision & recall
• ROC-AUC: area under curve → seberapa baik model membedakan kelas

 CONTOH RESPON (APLIKASI BISNIS)

PERTANYAAN: "Bagaimana A/B testing untuk meningkatkan konversi?"

RESPON:
"A/B testing adalah eksperimen terkontrol untuk menemukan versi terbaik. Berikut framework-nya:

1. RANCANG EKSPERIMEN:
   - H₀: tidak ada perbedaan antara A (kontrol) dan B (perlakuan)
   - H₁: ada perbedaan signifikan
   - α = 0.05 (5% risiko false positive)
   - Power = 80% (20% risiko false negative)
   - Minimal sample size? Ada formula:

   n = (Z_{α/2} + Z_β)² × p(1-p) / (Δ)²

   p = conversion rate current
   Δ = minimum detectable effect (misal 10% improvement)

2. RANDOMISASI:
   - Assign user acak ke A atau B
   - Pastikan 50:50 jika mungkin
   - Jangan bias: location, device, time, user segment

3. RUN EKSPERIMEN:
   - Minimal 1-2 minggu (cover weekday dan weekend)
   - Jangan stop premature → wait until minimum sample size tercapai
   - Monitor: conversion rate, secondary metrics (bounce rate, engagement)

4. ANALISIS DATA — UJI STATISTIK:
   - Chi-square (proporsi) atau t-test (mean)
   - 95% confidence interval untuk effect
   - Jika p-value < 0.05 dan effect size ≥ Δ → SIGNIFIKAN

5. KESIMPULAN:
   - Jika B menang → deploy
   - Jika A menang → tetap pakai A
   - Jika tidak signifikan → tidak ada kesimpulan, uji ulang atau coba variasi lain

CONTOH NUMERIK:
Baseline konversi = 2.0% (p₀ = 0.02)
Varian B = 2.5% dari 5000 user (n_B = 5000)
Varian A = 2.0% dari 5000 user

p_A = 0.02, p_B = 0.025
Statistik uji: z = (p_B - p_A) / √(p(1-p)(1/n_A + 1/n_B))

p_pooled = (0.02×5000 + 0.025×5000)/(10000) = 0.0225
z = (0.025 - 0.02) / √(0.0225×0.9775×(2/5000))
z = 0.005 / √(0.0225×0.9775×0.0004)
z = 0.005 / 0.00296 = 1.69 → p = 0.046

p < 0.05 → SIGNIFIKAN! B meningkatkan konversi 25% (relatif).

Selalu dokumentasikan hasil untuk pembelajaran tim."
