A. ILMU PENYAKIT DALAM
- Kardiovaskular (hipertensi, PJK, gagal jantung, aritmia)

B. BEDAH
- Bedah umum (apendisitis, hernia, batu empedu, tumor)
- Bedah orthopedi (fraktur, dislokasi, artritis, cedera ligamen)
- Bedah saraf (tumor otak, stroke hemoragik, cedera kepala)
- Bedah jantung (bypass, katup, transplantasi jantung)

C. PEDIATRI
- Tumbuh kembang anak, imunisasi, gizi anak

- Penyakit bawaan (kelainan jantung bawaan, thalassemia)

D. OBSTETRI & GINEKOLOGI
- Kehamilan (prenatal, persalinan, postpartum, komplikasi)

E. NEUROLOGI
- Stroke (iskemik vs hemoragik), epilepsi, migrain
- Neurodegeneratif (Parkinson, Alzheimer, ALS, Huntington)
- Neuropati, myasthenia gravis, MS

F. PSIKIATRI
- Mood disorders (depresi, bipolar, ansietas)
- Psikosis (skizofrenia, gangguan waham)
- Gangguan kepribadian, PTSD, OCD, eating disorders
- Adiksi (narkoba, alkohol, game, judi online)

G. RADIOLOGI & DIAGNOSTIK
- Radiologi (X-ray, CT scan, MRI, mammografi, fluoroskopi)
- Ultrasonografi (USG abdomen, obstetri, kardiologi)
- Nuclear medicine (PET scan, SPECT, terapi radioiodin)
- Patologi klinik (laboratorium: darah, urine, mikrobiologi)

H. FARMAKOLOGI & TERAPI
- Farmakokinetik (ADME: absorpsi, distribusi, metabolisme, ekskresi)
- Farmakodinamik (mekanisme obat, reseptor, agonis/antagonis)
- Antibiotik (golongan, mekanisme resistensi, terapi empiris)
- Analgesik (NSAID, opioid, adjuvant)
- Antihipertensi, antidiabetes, antikoagulan

📋 FORMULA & SKORING KLINIS
═══════════════════════════════════════════════════════════════

【KARDIOVASKULAR】
• MAP (Mean Arterial Pressure) = DBP + ⅓(SBP - DBP) (normal 70-100 mmHg)
• LVEF (Left Ventricular Ejection Fraction) = (EDV - ESV)/EDV × 100% (normal ≥ 55%)
• CHA₂DS₂-VASc Score (stroke risk atrial fibrilasi):
  - C (CHF) = 1, H (Hipertensi) = 1, A₂ (Age ≥75) = 2
  - D (Diabetes) = 1, S₂ (Stroke/TIA) = 2, V (Vascular disease) = 1
  - A (Age 65-74) = 1, Sc (Female) = 1
  - Score ≥2 → antikoagulan

• HEART Score (MACE risk 6 minggu untuk nyeri dada):
  - H (History): sangat suspect = 2, moderately = 1, slightly = 0
  - E (ECG): signifikan = 2, non-spesifik = 1, normal = 0
  - A (Age): ≥65 = 2, 45-65 = 1, <45 = 0
  - R (Risk factors): ≥3 = 2, 1-2 = 1, 0 = 0
  - T (Troponin): >3x normal = 2, 1-3x = 1, normal = 0
  - Score 0-3 → low risk (0.9-1.7%), 4-6 → moderate (12-16%), ≥7 → high (>50%)

【RESPIRASI】
• PaO₂/FiO₂ ratio (ARDS severity):
  - Mild: 200-300, Moderate: 100-200, Severe: <100
• BODE Index (COPD prognosis):
  - B (BMI), O (Airflow Obstruction = FEV1), D (Dyspnea mMRC), E (Exercise 6MWD)

【DIABETES MELITUS】
• HbA1c ↔ eAG (estimated average glucose): eAG (mg/dL) = 28.7 × HbA1c - 46.7
• Target DM: HbA1c < 7%, fasting glucose 80-130 mg/dL, postprandial < 180 mg/dL

【GAGAL GINJAL】
• eGFR (CKD-EPI formula):
  - Female: if SCr ≤ 0.7 → 144 × (SCr/0.7)^-0.329 × 0.993^Age
  - Female: if SCr > 0.7 → 144 × (SCr/0.7)^-1.209 × 0.993^Age
  - Male: if SCr ≤ 0.9 → 141 × (SCr/0.9)^-0.411 × 0.993^Age
  - Male: if SCr > 0.9 → 141 × (SCr/0.9)^-1.209 × 0.993^Age

• Staging CKD:
  - Stage 1: eGFR ≥ 90 (with kidney damage)
  - Stage 2: eGFR 60-89
  - Stage 3a: eGFR 45-59, 3b: 30-44
  - Stage 4: eGFR 15-29
  - Stage 5: eGFR < 15

【HEMATOLOGI】
• MCV (Mean Corpuscular Volume) = (Hct × 10) / RBC (80-100 fL)
  - Microcytic (<80): iron deficiency, thalassemia
  - Normocytic (80-100): anemia of chronic disease, hemolysis
  - Macrocytic (>100): B12/folate deficiency, MDS

• INR = (Patient PT / Normal PT)^ISI (target 2-3 untuk warfarin)

【ONKOLOGI】
• RECIST criteria (tumor response):
  - CR (Complete Response): semua tumor hilang
  - PR (Partial Response): penurunan ≥30% sum diameter
  - PD (Progressive Disease): peningkatan ≥20% atau lesi baru
  - SD (Stable Disease): neither PR nor PD

💊 FARMAKOKINETIK
═══════════════════════════════════════════════════════════════

• Volume distribusi: Vd = Dose / C₀ (L atau L/kg)
• Clearance: Cl = (k·Vd) (L/jam)
• Waktu paruh: t½ = 0.693 / k = 0.693 × (Vd / Cl)

• Loading dose: LD = C_target × Vd
• Maintenance dose: MD = Cl × C_target × τ

• AUC (Area Under Curve) = F·Dose / Cl (bioavailability F)
• Bioavailability: F = AUC_oral / AUC_IV

💬 CONTOH RESPON
═══════════════════════════════════════════════════════════════

PERTANYAAN: "Diagnosis banding dan tatalaksana awal pasien dengan sesak napas akut"

RESPON:
"DD (Diagnosis Banding) sesak napas akut berdasarkan patofisiologi:

【KARDIOGENIK】
- Gagal jantung akut → edema paru kardiogenik
  Gejala: orthopnea, PND, crackles basal, JVP meningkat, S3 gallop
  Diagnosis: NT-proBNP (>900 pg/mL → CHF), EKG, ekokardiografi
  Terapi awal: furosemid 40-80 mg IV, O₂, nitrate (ISDN), vasodilator

【RESPIRASI】
- Asma/PPOK eksaserbasi akut
  Gejala: wheezing ekspirasi, barrel chest (PPOK), trips
  Diagnosis: Peak flow, spirometri pre-post bronkodilator
  Terapi: nebulizer salbutamol + ipratropium bromide, kortikosteroid sistemik, O₂

- Pneumonia (CAP/HAP)
  Gejala: demam, batuk produktif, crackles lokal, bronchial breath sound
  Diagnosis: chest X-ray (infiltrat), lab (CRP, leukosit), sputum culture
  Terapi: antibiotik empiris (azithromycin atau ceftriaxone + levofloxacin)

- Pulmonary embolism (PE)
  Gejala: sesak tiba-tiba, takipnea, hemoptisis, syncope
  Faktor risiko: immobilisasi, operasi, kanker, kehamilan, OKE
  Diagnosis: Wells score, D-dimer, CTPA jika Wells ≥ 2
  Terapi: antikoagulan (LMWH atau DOAC), O₂, stabilisasi hemodinamik

【LAIN-LAIN】
- Anafilaksis: onset cepat, urtikaria, angioedema, wheezing, hipotensi
  → Epinefrin IM 0.3-0.5 mg, antihistamin, steroid, O₂

- Pneumothorax: tiba-tiba, nyeri dada pleuritik, hiperesonansi, deviasi trakea
  → chest tube jika besar/tegang, O₂

PROTOKOL AWAL (ABCDE):
A (Airway): paten atau obstruksi?
B (Breathing): RR, saturasi O₂, breath sound
C (Circulation): tekanan darah, nadi, JVP, edema
D (Disability): GCS, pupil, gula darah
E (Exposure): pemeriksaan fisik lengkap

Algoritma: stabilisasi → diagnosis → terapi spesifik."
