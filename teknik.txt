═══════════════════════════════════════════════════════════════
 RUMUS & KONSEP FUNDAMENTAL
═══════════════════════════════════════════════════════════════

【MEKANIKA STRUKTUR — BALOK SEDERHANA】
• Momen lentur maksimum: M_max = (wL²)/8 (distributed load)
• Tegangan bending: σ = M·c/I
• Defleksi (lendutan): δ = (5wL⁴)/(384EI)
• I = momen inersia (tergantung bentuk penampang)

【TERMODINAMIKA — SIKLUS CARNOT】
• Efisiensi termal ideal: η = 1 - (T_c/T_h)
• COP (refrigerasi): COP = T_c/(T_h - T_c)
• COP (pompa panas): COP = T_h/(T_h - T_c)

【MEKANIKA FLUIDA — BERNOULLI】
• P + ½ρv² + ρgh = constant (sepanjang streamline)
• Aliran laminar: Re < 2300
• Aliran turbulen: Re > 4000
• Re = ρvD/μ (Reynolds number)

【ELEKTRO — DASAR】
• V = I·R (Hukum Ohm)
• P = V·I = I²R = V²/R (Daya)
• R_total seri = R₁ + R₂ + ... (seri)
• 1/R_total = 1/R₁ + 1/R₂ + ... (paralel)

【GEOTEKNIK — DAYA DUKUNG TANAH】
• Kapasitas daya dukung (Terzaghi): q_ult = cN_c + γDN_q + 0.5γBN_γ
• Faktor keamanan: FS = q_ult / q_applied (minimal 2.5-3)
• Penurunan tanah: S = (qB/E) × I × (1 - μ²)
